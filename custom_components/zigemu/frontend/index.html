Create your first coordinator

A coordinator is an emulated Ember (EZSP) Zigbee stick listening on a TCP port. Point Zigbee2MQTT or ZHA at it, then add virtual devices and pair them. You can create as many coordinators as you like, one port each.

    Settings

    Profiles switched off are hidden from Add device. Devices already using them keep working.

    Tags organise your devices (a room, a floor, a test bench…); a device can have several. Add them when you create a device or in its settings (ⓘ), where new ones are created on the fly. Rename a tag by editing its name (every device follows); deleting a tag removes it from its devices. Usage counts cover every coordinator.

    Saved views

    A view saves the device list's search, filters (tags included) and grouping. Pick one from the list above the devices.

    Import from Zigbee2MQTT

    Drop or pick a file exported from Zigbee2MQTT: Settings → Tools → Download state (JSON), the bridge/devices payload, or database.db. It is read in your browser; only the devices you select are saved.
